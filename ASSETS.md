# Assets and attribution

All app screenshots now come directly from the running Aroha Music Android app, version 1.1.0 (version code 2), using the current local preview APK. Original, full-frame PNG captures are in `design/app-captures/`; local capture metadata is excluded from publication. The deployable site uses 540px and 1080px WebP versions in `dist/assets/screenshots/`; only resizing and compression were applied. No UI, songs, controls or artwork were fabricated or replaced. The page identifies these as preview-build screenshots because the published release may differ.

The screens show discovery, the player, the song library and Glimpses. The library was populated through normal discovery/playback and a favorite saved in the disposable emulator session. External recordings, artwork and provider brands belong to their respective owners.

The Aroha icon and Plus Jakarta Sans font were copied from the Android project with their existing licenses. The website retains GPL-3.0-or-later. The font’s SIL Open Font License is in `dist/assets/FONT-LICENSE.txt`.

`social-cover.png` is an original, code-drawn brand card. There is no stock photography, fictional player, generated lyric demo or website audio in the current design.
